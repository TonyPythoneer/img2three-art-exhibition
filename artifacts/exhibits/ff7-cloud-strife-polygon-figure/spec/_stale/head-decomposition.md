## 1. 為什麼要拆：上一輪失敗的病灶

上一輪 `createHead.ts` 用 `ring()` × 8 邊 × `loft()` × 8 段做髮帽，機械閘門全綠但目視不合格。
病灶不在尺寸，在**建構方式**：ring-loft 的相鄰段法線夾角天生很小，做出來一定是光滑的蛋。
藍本的身分就是**稜角**——`flatShading` 只是渲染旗標，救不了本來就沒有稜的拓樸。

拆件不是為了整齊，是為了讓每一件都有**它自己擋得住的失敗模式**：
髮帽擋「太圓」，髮刺擋「變成豪豬」，臉擋「被髮帽吃掉」，眼睛擋「看得到矩形接縫」。

## 2.5 背面沒有髮刺 ⇒ 背視是頭型的唯一權威視角

這是這尊最重要的一條推論，值得單獨一節。

九根髮刺全部長在**前半部與頂部**，背面一根都沒有。所以背視圖裡看到的那個多面體外殼，
是唯一一個**沒有被髮刺遮擋、也沒有被髮刺撐開**的髮帽讀數。前視與兩個 profile 的外輪廓
都是「髮帽 ∪ 髮刺」的聯集，量出來的是髮型的剪影；只有背視量到的是髮帽本身。

而髮帽是套在顱骨上的殼。**髮帽的內表面 = 顱骨的外包絡。** 所以：

> 背視 → 髮帽殼形狀 → 減去殼厚 → 顱骨形狀。
> 顱骨不能從正面推，正面全是頭髮。

從背視能直接反推出來的五件事：

**1. 髮帽背面外形：窄裙 → 中上最寬 → 快速收頂。已逐列量測。**
`capShell.widthProfile`（back）：

| Y | 寬 | 讀法 |
|---|---|---|
| 0.7189 | 0.1110 | 後頸裙最窄處 |
| 0.7768 | 0.1641 | 裙往上放 |
| 0.7961 | 0.2099 | |
| **0.8154** | **0.2546** | x0 −0.1285 / x1 +0.1261，**左右對稱**，乾淨 |
| 0.8347 | 0.2605 | x1 +0.1634 被角色右側髮刺污染，不可用 |
| 0.8540 | 0.2727 | 同上（x1 +0.1454） |
| 0.8926 | 0.1641 | 上方倒角開始 |
| 0.9119 | 0.0604 | 快速收頂 |

所以**不是**「下寬上收的梯形」（我先前這樣寫是錯的），是**中上段最寬、下有窄裙、上快速收頂**。
`ring()` 8 邊等徑堆疊做不出這條曲線，這是它變成蛋的第二個原因（第一個是分面太細）。

**1b. 髮帽最大寬 = 0.255，取自左右對稱的那一列。**
三個候選數字互相矛盾，都要交代清楚：
`head-measurements.json` 0.216（每列連續髮色區間，偏小）／
`capShell.maxWidthNorm` 0.2727（最長 run，被角色右側寬髮刺併進來，偏大）／
`capCore` R=16 開運算 0.2340（侵蝕過頭，偏小）。
定案用 **Y=0.8154 那一列的 0.2546**：它是唯一左右近乎對稱（±0.127）的列，
代表那一列的 run 沒有含到髮刺。

**1c. 開運算的 sweep 自己證實了「背面沒有髮刺」。**
`capCore.sweep` 的存活像素數：front 18769→4616（掉 75%，R=8→10 有懸崖）、
left R=10→12 有懸崖、right R=14→16 有懸崖，
**back 27997→23548（只掉 16%，整條曲線平滑無懸崖）**。
懸崖 = 髮刺被侵蝕斷開、髮帽碎成好幾塊。背面沒有懸崖，因為它本來就是一整塊。
這是對「背面沒有髮刺」的獨立機器驗證，不是目視。

**2. 枕骨最突點在 `Y ≈ 0.82`。**
背視殼身有一條倒 V（chevron）接縫，頂點約在殼高的 45%。殼從下緣 `Y≈0.707` 到頂
`Y≈0.96`，45% 落在 `0.707 + 0.45×0.253 ≈ 0.821`。低多邊形封後腦時，chevron 頂點就是
枕骨最突點。顱骨的最大 Z（向後）要放在這個高度，不要放在中間。

**3. 髮帽下緣不是水平的：後中比兩側低 0.097。已量測。**
`capShell`（背視，權威）：`hemYNormAtCenter = 0.7069`、`hemYNormAtSide = 0.8034`。
差 **0.097**，比先前用汙染值估的 0.05 大一倍。後低側高 ⇒ 髮帽有一圈**後裙**蓋住後頸，
兩側往上收讓耳朵露出來。

這條直接決定耳朵怎麼放：**耳朵活在側邊 `Y ≈ 0.70 ~ 0.80` 這條帶裡**。
上一輪把耳朵做成戳出髮帽的方塊，病灶不在耳朵尺寸，在把髮帽下緣當成水平的了。

**3b. 髮帽寬深比 1.22:1，殼厚 ≈ 0.005。已量測。**
`capShell.maxWidthNorm`：正視 `0.2733 @Y=0.8331`、背視 `0.2727 @Y=0.854`、
左 profile（＝前後深度）`0.2243 @Y=0.8477`。寬 0.273 ÷ 深 0.224 = **1.22**，
顱骨寬於深，與 §2.5-1 的圓角梯形一致。
`rimThicknessPx = 2`（背視，髮帽橫跨約 107 px）⇒ 殼厚 ≈ 0.019 × 0.273 ≈ **0.005**。
顱骨外包絡 = 髮帽內表面 = 髮帽外形 − 0.005。這個殼很薄，顱骨幾乎就是髮帽的形狀。

**4. 整個髮型往角色右邊偏，而且偏的是髮帽本身不只是髮刺。**
髮色遮罩質心：背視 `x=213.89`／圖寬 391（中心 195.5）→ 偏 **+0.047** 往角色右；
正視 `x=166.24`／圖寬 384（中心 192）→ 偏 **0.067** 也是往角色右。
背視幾乎沒有髮刺，它那 +0.047 只能來自殼本身 ⇒ **髮帽殼是偏心的**。
最長那根髮刺也長在同一側，整個髮型是往角色右掃的一致設計，不是隨機不對稱。
顱骨可以對稱，但髮帽要照這個偏移擺。

**5. 頸柱寬約髮帽最大寬的 0.25。**
J5 @10× 量：頸柱橫跨 ≈31 px、髮帽橫跨 ≈126 px（原圖像素）→ 比值 0.246。

### 因此顱骨的建構規則

| 規則 | 數值 | 來源 |
|---|---|---|
| 冠狀斷面 | 圓角梯形，下寬上收 | 背視八邊外輪廓 |
| 最大後突 Y | 0.821 | 背視 chevron 頂點 |
| 顱骨側面上界 | 不得高於髮帽內表面 | 髮帽殼厚（`capShell.rimThicknessPx`）待量 |
| 耳朵帶 | Y 0.707 – 0.757 | 後低側高的下緣 |
| 頸／髮帽寬比 | 0.246 | J5 |
| 顱頂細節 | 不用做 | 全被髮帽蓋住，只要套得下不穿模 |

**顱骨對稱、髮帽偏心**——這兩件事分開，是為了讓顱骨的閘門可以用左右對稱當斷言，
而不會被髮型的刻意不對稱污染。

## 3. 建構順序與各自的閘門

`structure_decomposition.md` 的執行序：先定 scaffold，再各自造形，最後才整合。

```
1. head-bare   →  bbox 斷言 + 五視角 render + 「臉是平滑膚面、無鼻無嘴」目視
                  ★ ≥18° 分面斷言**只套用在 hair-cap**，不要套在 skull（G10）
2. eyes        →  貼在 head-bare 上單獨拍，斷言：任一視角看不到四邊形邊界
3. hair-cap    →  法線夾角分佈斷言（門檻用平滑球夾）+ 蓋得住 skull 不穿模
4. spike-*     →  逐根對照放大圖：起點/方位/長度/寬度四個數字各自比對
5. 整合        →  check_part_coverage + 四視角 silhouette IoU + explode/click
```

閘門的門檻一律用**造假 frame** 夾出來，不要憑感覺填：
- 「太圓」的下界 → 拿一顆同尺寸的平滑球跑同一支斷言，它的值就是不合格線。
- 「豪豬化」的下界 → 拿一組等長等角的髮刺跑，它的方位角變異數就是不合格線。
