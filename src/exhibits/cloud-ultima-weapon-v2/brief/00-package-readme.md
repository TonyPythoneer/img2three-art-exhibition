# Ultima Weapon img2threejs Review Package

This package contains reviewed prompts, component tables, reference images, and isolated artwork assets for reconstructing the FF7 Ultima Weapon in img2threejs.

## Assets

- `assets/artwork-sword-crop.webp` — sword-only crop with the original white background; use for authoritative color, shape, measurement, and overlay comparison.
- `assets/artwork-sword-transparent.webp` — cleaned transparent cutout; use only as a subject-isolation aid.

Geometry boundaries must be measured directly from the authority artwork.

## Important geometry rules

- Treat the weapon as a PS1-era low-poly model with a small number of purposeful planar faces.
- The pale outer crystal shell is sharpened at the tip and along both side edges.
- The inner purple crystal insert is not sharpened.
- Use four driver components, two on each side of the guard.
